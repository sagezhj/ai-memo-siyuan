1. 思源笔记连接

在思源「设置 → API」里开启 API 服务，把端口和认证码填进来。默认地址 http://127.0.0.1:6806。

文档头（标题下那段元信息）只在首次创建该对话文档时写入；之后增量同步只更新正文与文档标题。想让新设置生效，可在「本地记录」里删除该记录后重扫，或整篇重建。
